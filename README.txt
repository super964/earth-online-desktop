地球 Online · Earth Online v1.0.0
=================================

一个可离线启动、联网获取真实地球数据的 3D 数字孪生桌面应用。
无需安装，解压后双击 "Earth Online.exe" 即可运行。

■ 运行要求
  - Windows 10 / 11 64 位
  - 支持 WebGL2 的显卡（集成显卡亦可）
  - 建议 8GB 内存；首次启动需要联网

■ 快速开始
  1. 双击 Earth Online.exe。
  2. 等待 3～10 秒，地球表面、地震、野火、风暴等图层会自动加载。
  3. 拖动旋转地球，滚轮缩放；点击地球任意位置可探测当地实时天气、
     当地时间与附近灾害。
  4. 右侧 "LIVE" 信息流会滚动显示正在发生的事件，点击条目可飞过去查看。
  5. 左下角 "TIME MACHINE" 可以回看最近 30 天的地震与自然事件。

■ 快捷键
  /      搜索地点
  T      打开 / 关闭时间机器
  R      立即刷新数据
  G      打开操作指南
  Esc    关闭弹窗
  鼠标拖动旋转 · 滚轮缩放 · 点击探测

■ 数据来源（均为公开实时接口）
  - 地震：USGS Earthquake Hazards Program
  - 自然事件 / 野火 / 风暴：NASA EONET
  - 气象预警：NOAA / National Weather Service
  - 极光：NOAA SWPC
  - 火流星：NASA CNEOS
  - 国际空间站：WhereTheISS.at
  - 天气 / 当地时间：Open-Meteo
  - 地点反查：BigDataCloud
  - IP 定位：ipwho.is

■ 离线与隐私
  - 应用本身不收集、不上传任何个人数据。
  - 所有网络请求仅用于获取上述公开数据。
  - 断网时仍可启动，并显示最近一次成功获取的数据或合成演示数据。
  - 游戏进度（积分、等级、探测记录）只保存在本机。

■ 常见问题
  - Windows 提示 "已保护你的电脑"：这是未签名应用的正常提示。
    点击 "更多信息" → "仍要运行"。
  - 首次启动较慢：正在从多个公开数据源拉取数据，稍等片刻即可。
  - 画面卡顿：可在 Windows 显示设置中关闭 "透明效果"，
    或更新显卡驱动。
  - 想重置进度：打开 OPERATOR 面板，点击 "RESET PROGRESS"。
